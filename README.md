# Somos Crédito

Examen técnico orientado al análisis de morosidad de créditos y a la construcción de un modelo de clasificación binaria para predecir si un crédito cae en mora antes del mes 6 de vida.

## Objetivo

El objetivo del examen es trabajar con una base de datos de créditos y pagos para calcular indicadores de morosidad, generar curvas de maduración por cohorte de desembolso y entrenar un modelo de clasificación binaria.
